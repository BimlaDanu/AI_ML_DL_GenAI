### CNN-Keras

This project explores Convolutional Neural Networks (CNNs) for image classification using and TensorFlow and Keras. The implementation focuses on understanding how CNNs learn visual patterns such as edges, textures, and shapes from image data.

The project includes:
- Image preprocessing and normalization
- CNN model design with convolution and pooling layers
- Model training and evaluation
- Accuracy and loss visualization
- Feature extraction using deep learning

The goal of this project is to build an intuitive understanding of computer vision and deep learning workflows using simple CNN architectures.
